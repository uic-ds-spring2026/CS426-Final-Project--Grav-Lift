# Grav-Lift

**CS 426 Final Project**
**Authors: Rafael Matouk, Andrew ----, Fernando Lopez

## Overview
Grav-Lift is a game development project created for the CS 426 course. The project is primarily built using the Unity engine and utilizes C#, HLSL, and ShaderLab for its core systems, gameplay mechanics, and custom visuals. 

## Repository Structure
* **`GravLift/`**: The main Unity project directory containing all game assets, scripts, and scenes.
* **`Notes from alpha testing.txt`**: Documentation of gameplay feedback, bugs, and iterative improvements identified during the alpha phase.
* **Team OKRs (Objectives and Key Results)**: Individual goal-tracking files for the development team.
  * `FernandoOKR.txt`
  * `RafaelMaatoukOKR.txt`
  * `andrewOKR.txt`

## Getting Started

### Prerequisites
* **Unity Engine**: Ensure you have the compatible version of Unity installed (check project settings if a specific version is required).
* **Git**: For version control and repository management.

### Installation
1. Clone the repository:
   ```bash
   git clone [https://github.com/uic-ds-spring2026/CS426-Final-Project--Grav-Lift.git](https://github.com/uic-ds-spring2026/CS426-Final-Project--Grav-Lift.git)

2. ​Open Unity Hub.
3. ​Select Open and navigate to the GravLift directory inside the cloned repository.
4. ​Launch the project.
