# Grav-Lift

**CS 426 Final Project**

## Overview
Grav-Lift is a game development project created for the CS 426 course. The project is primarily built using the Unity engine and utilizes C#, HLSL, and ShaderLab for its core systems, gameplay mechanics, and custom visuals.

## Getting Started

### Prerequisites
Before you begin, ensure you have the following tools and libraries installed:
* **[Unity Hub & Unity Editor](https://unity.com/download)**: (Check the Project Settings for the exact required Unity version)
* **[Git](https://git-scm.com/downloads)**: For version control and cloning the repository.
* **Code Editor**: Visual Studio 2022 or Visual Studio Code (with appropriate C# and Unity extensions).

## Installation

Follow these ordered steps to set up the project locally on your machine and install dependencies:

1. **Clone the repository**
   Open your terminal or command prompt and run the following command:
   ```bash
   git clone [https://github.com/uic-ds-spring2026/CS426-Final-Project--Grav-Lift.git](https://github.com/uic-ds-spring2026/CS426-Final-Project--Grav-Lift.git)

```
 2. **Navigate to the project directory**
   ```bash
   cd CS426-Final-Project--Grav-Lift
   
   ```
 3. **Add the project to Unity Hub**
   * Open **Unity Hub**.
   * Click on the **Add** (or **Open**) button.
   * Navigate to the cloned repository folder and select the GravLift directory.
 4. **Install Dependencies**
   * Upon opening the project for the first time, Unity will automatically resolve and download any required packages and dependencies via the Unity Package Manager. This may take a few minutes to complete.
## Usage
Here is how you can interact with and test the game locally:
 1. **Open the Main Scene**
   * In the Unity Editor, navigate to the **Project** window at the bottom.
   * Go to Assets/Scenes/ (or your designated scenes folder) and double-click the main game scene to load it into the hierarchy.
 2. **Run the Game**
   * Press the **Play** button (▶) at the top center of the Unity Editor to start the game in the Game view.
 3. **Controls**
   * **Movement:** W A S D or Arrow Keys
   * **Action/Jump:** Spacebar
   * *(Note: Please update these controls to match the exact inputs for Grav-Lift)*
 4. **Stopping the Game**
   * Press the **Play** button again to exit Play Mode and return to the editor.
